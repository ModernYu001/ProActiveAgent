# Slack 斜杠命令触发 GitHub Actions —— 配置指南

做完后：在 Slack 任意频道敲 `/proactive` 跑一轮资讯，敲 `/ytreport` 发一次 YouTube 日报。
全程免费（Cloudflare Workers 免费档每天 10 万次请求）。

---

## 第 1 步：部署 Worker（约 5 分钟）

1. 登录 [dash.cloudflare.com](https://dash.cloudflare.com) → 左侧 **Workers & Pages** → **Create** → **Create Worker**。
2. 名字改成 `slack-trigger` → **Deploy**（先部署默认的 hello world）。
3. 点 **Edit code** → 全选删掉 → 粘贴 `worker.js` 的全部内容 → **Deploy**。
4. 记下 Worker 地址：`https://slack-trigger.<你的子域>.workers.dev`。

## 第 2 步：建一个专用 PAT（约 3 分钟）

不要复用之前那个大权限 token，建个最小权限的：

1. GitHub → Settings → Developer settings → **Fine-grained tokens** → Generate new token。
2. 名字 `slack-trigger`；Repository access 选 **Only select repositories** → 勾 `ProActiveAgent` 和 `SlackYT`。
3. Repository permissions 只开一项：**Actions → Read and write**。其他全部 No access。
4. 生成后复制 token。

## 第 3 步：给 Worker 配两个 Secret（约 2 分钟）

Worker 页面 → **Settings** → **Variables and Secrets** → **Add**，类型选 **Secret**：

| 名字 | 值 |
|---|---|
| `GH_PAT` | 第 2 步的 token |
| `SLACK_SIGNING_SECRET` | Slack App 页面 → Basic Information → App Credentials → **Signing Secret**（点 Show 复制） |

Slack App 就是你当初建 Incoming Webhook 用的那个，在 [api.slack.com/apps](https://api.slack.com/apps) 里。

## 第 4 步：在 Slack App 里建两个斜杠命令（约 5 分钟）

Slack App 页面 → 左侧 **Slash Commands** → **Create New Command**：

| 字段 | 命令 1 | 命令 2 |
|---|---|---|
| Command | `/proactive` | `/ytreport` |
| Request URL | Worker 地址（两个填一样） | 同左 |
| Short Description | 跑一轮资讯监控 | 发一次 YouTube 日报 |

保存后，左侧 **Install App** → **Reinstall to Workspace**（加了新命令必须重装一次才生效）。

## 第 5 步：测试

任意频道输入 `/proactive` → 应立刻看到一条只有你可见的"🚀 已触发"回执 → 一两分钟后频道里出现资讯推送（如果全被去重掉则没有消息，属正常）。

---

## 排错

| 症状 | 原因 | 解法 |
|---|---|---|
| `bad signature` | Signing Secret 填错 | 重新从 Basic Information 复制 |
| `触发失败 HTTP 401/403` | PAT 错误或权限不够 | 确认 PAT 勾了两个仓库 + Actions read&write |
| `触发失败 HTTP 404` | 仓库/文件名不对 | 检查 worker.js 里 ROUTES 的 repo 和 workflow 文件名 |
| 命令无响应 | 没重装 App | Install App → Reinstall to Workspace |
| dispatch_failed | Slack 3 秒超时 | 偶发，重试即可 |

## 以后加新命令

在 `worker.js` 的 `ROUTES` 里加一行（命令 → 仓库 + workflow 文件名），Deploy，然后去 Slack App 里建同名 Slash Command 即可。
